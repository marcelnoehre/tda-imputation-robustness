# TDA Imputation Robustness
Empirical study to evaluate "The Robustness of Topological Data Analysis under Imputation-Induced Perturbations"

## Setup Instructions

The environment is pinned in `uv.lock` (Python >= 3.11):

```bash
uv sync
```

Unit tests (a few seconds): `uv run pytest`.

Without uv, install the same pinned versions with `pip install -r requirements.txt` (generated by `uv export --format requirements-txt --no-hashes --no-dev`).

## Configuration

`config/experiments.yaml` holds the full experimental grid (experiments, mechanisms, missing rates, imputers, filtrations, distances), the seeds and every hyperparameter. `src/constants.py` only defines keys and labels.

> [!WARNING]  
> Before running experiments, set `runtime.workers` in `config/experiments.yaml` to your desired number of parallel workers (`workers > 1` requires `n_jobs: 1`).

Intermediate results are cached in `.cache/`, keyed by the function arguments but not by the configuration. After changing a hyperparameter, delete the affected cache entries.

## Run Experiments

To run the experiments with **all datasets**, use:

```bash
python main.py
```

To run the experiments with a specific subset of datasets, pass their IDs as arguments:

```bash
python main.py 123
```

Multiple dataset IDs can be provided:

```bash
python main.py 123 321
```

To run only some of the experiments of `config/experiments.yaml`, name them:

```bash
python main.py -e baseline topological_metrics_mr
```

## Dataset Selection and Archive

`python scripts/select_datasets.py` reproduces the selection of the 15 OpenML datasets (automatic filters plus the manual exclusion lists) and checks it against `src/constants.py`.

After the experiments, `python scripts/export_archive.py archive/` writes every original and reconstructed persistence diagram to `archive/diagrams.h5` (layout in the script's docstring), together with `results/*.csv` and the configuration, for the Zenodo archive.

## Reproduce the Paper

`main.py` runs every experiment used in the paper and writes one file per experiment to `results/`:

| File | Experiment |
|------|------------|
| `comparison_metrics_results.csv` | Raw imputation error (RMSE, MAE) |
| `topological_metrics_results.csv` | All imputers, VR, MAR, 5/10/25% |
| `topological_metrics_mr_results.csv` | kNN, VR, all mechanisms, 1-40% |
| `topological_metrics_filtration_results.csv` | kNN, VR/DTM/KD, MAR, 5/10/25% |
| `baseline_results.csv` | Shuffled ground truth, random subsample, complete-case analysis |

`notebooks/tmlr_figures.ipynb` reads these files and writes all results tables and figures of the paper to `figures/tmlr/`, and prints the statistics quoted in the text.
